# Pet's Pet 1.2.0

状态：网页样式已由用户确认，发布 1.2.0；真实桌面场景按下方步骤验收。日期：2026-10-16。

## 实际重启验收结果

2026-10-16，用户确认重启 Codex 后宠物本体已显示、额度组件未出现。1.2.0 的恢复修复未通过真实重启验收；单次授权后正常显示不能作为重启验收。保留此版本，后续修复另存 1.2.1。

## 用户可见变化

- 菜单栏新增「外观 → 跟随系统／浅色／深色」，默认跟随系统，选择保存在本机，下次启动继续使用。
- 深色组件使用深色半透明底板、浅色数字和标签、低亮度底轨；保持 1.1.0 的双 C 轨道、上端固定的剩余进度和太极线。
- 使用用户指定的猫耳双 C 图标：蓝色底板应用图标，以及由系统适配菜单栏背景的单色模板图标。
- 菜单按状态、额度信息、常用操作与外观、检测与诊断、退出分组。
- 额度信息新增可用重置卡数量、最近到期时间，使用本机时区；与 5H／W 信息共用官方只读接口，不增加兑换操作。
- 数量以官方 `availableCount` 为准；缺失不能显示为 0。仅有部分明细时显示「已知最近到期」；未提供明细、无到期限制、数量为 0、过期等待刷新分别显示对应状态。
- 组件默认与宠物水平居中，位于下方；在已确认的宠物浮层中收集操作条和任务提示的可访问元素几何位置并避让。下方空间不足时切到整组内容上方，增加 16 点回切余量以减少抖动；上下均无空间时隐藏。屏幕左右边缘允许水平调整以保持可见。

## 重启恢复修复

- Codex 进程变化后重新建立辅助功能连接；在已获系统授权的前提下，使用 Electron 官方的 `AXManualAccessibility` 初始化可访问树。
- 窗口读取失败后清除旧引用，按 0.4、0.8、1.6、3.2、5 秒上限重试，成功后恢复正常检测频率。
- 监听 Codex 启动和退出，手动重新检测也会重建连接；监测计时器在同一队列上启动、停止，重复启动保持幂等。
- 区分读取失败、等待初始化、扫描未完成、未显示宠物和多个候选；不再把读取失败立即覆盖成普通等待状态。
- 保留唯一宠物身份校验、屏幕可见性校验和鼠标穿透。不会修改 Codex 文件、登录权限或发送键鼠事件。

- 真实 Codex 连续重启场景尚未验收；恢复策略检查不能替代实际客户端重启测试，不宣称 BUG 已在真实桌面验收通过。
- 操作条、任务卡片的真实可访问结构与展开／收起避让、跨屏、全屏／桌面切换、睡眠唤醒仍需正式入口实测。无法完整读取结构时保持隐藏，不以窗口大小猜测宠物。

## 桌面验收步骤

1. 显示宠物，核对组件默认位于整组内容下方；展开、收起操作条和任务卡片，确认无遮挡。
2. 将宠物靠近屏幕底边，确认组件自动转到上方；向上移出足够空间后恢复下方，边界附近不反复跳动。
3. 从菜单依次选择浅色、深色、跟随系统，确认即时变化；退出再启动 Pet's Pet，确认选择保留；切换 macOS 外观确认自动模式。
4. 核对菜单栏重置卡数量、最近到期时间与 Codex 当前账号一致，刷新正常，未知信息不显示为 0。
5. Pet's Pet 保持运行，连续退出／启动 Codex 至少两次，每次显示宠物后组件自动恢复；隐藏再显示宠物也能恢复，无需重启 Pet's Pet。
6. 进行跨显示器、切换桌面／全屏、睡眠唤醒和断网重试验证；检查组件不在错误桌面残留，未知额度无伪造值。
