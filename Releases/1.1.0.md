# Pet's Pet 1.1.0 更新日志

发布日期：2026-10-16。相较 1.0.0，更新双 C 太极样式，并修正进度条减少方向。

## 界面调整

- 将完整双圆改为开口相对的双 C 轨道，开口 110°，保留 250° 有效弧长；满额度时仍保留开口。
- 保持左侧绿色 5H、右侧蓝色 Weekly；绿色降低亮度和饱和度，视觉更柔和。
- 保持数字 18 号、隐藏百分号，W / 5H 标签分别位于中央上方和下方。
- 进度条线宽调整为 5.5 点，白色轨道不透明度为 90%。
- 太极分割线按参考曲度调整为左下连接右上，线宽 1.7 点；两端渐隐并压在白色轨道下方，使衔接更自然。
- 圆底与中间区域连成一片，左侧半透明白色、右侧浅深色；深色从右向左渐淡，减少硬切边界。
- 保持迷你收腰胶囊、半透明白底和阴影。可见尺寸为 128 × 64 点，含阴影留白的窗口为 144 × 80 点。

## 问题修复

- 修复额度减少时彩色进度两端同时变化的问题：现在固定上端，仅下端向上收缩。
- 进度长度按 C 形轨道的有效弧长映射；0 时不显示彩色进度，100 时覆盖整个 C 形轨道。

## 预览与发布

- 使用与 App 相同的原生视图生成网页预览，可在右侧比较参考图，无需反复安装和重新授权。
- 补充 100 / 75 / 50 / 25 / 0 的进度样本，以及读取中、读取失败、数据过期等状态的评审图。
- 每个正式版本只保留一份最终安装包，并附更新日志、预览、清单和校验文件；有匹配源码时一并保留最终源码压缩包。

## 验证情况

- 最终样式、进度方向和柔和绿色已由用户通过预览确认。
- 原生渲染的 60 项像素检查通过，覆盖两侧进度长度及上端固定。
- 组件定位等核心规则此前通过 14 组、54 项断言；这些检查不能替代真实桌面操作。
- 最终应用已完成生产构建、签名、压缩包完整性与哈希校验，并已更新固定入口。
- 本次日志整理和安装包归并未重新编译、签名或替换已安装应用；正式版本号仍为 1.1.0。

## 已知限制

- 新版启动时系统提示需要辅助功能权限；重新授权后的真实桌面跟随尚未复验。
- 跨屏、全屏与桌面切换、睡眠唤醒、断网与退出登录等系统场景尚未完整实测。
- 预览中的 68 / 42 等数字是明确标注的样式样本，不代表账号实时额度；App 继续读取真实额度。
