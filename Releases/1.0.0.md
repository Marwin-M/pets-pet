# Pet's Pet 1.0.0 更新日志

发布日期：2026-10-16。首个正式定稿版本，作为后续迭代的基线。

## 功能

- 跟随 Codex 宠物显示、隐藏和移动，宠物是唯一定位锚点。
- 显示 5 小时和周剩余额度，通过 Codex 自带的官方服务读取真实数据；重置时间可在菜单栏查看。
- 使用独立 macOS App 和辅助功能权限读取宠物位置，不修改 Codex 客户端、不注入进程。
- 组件支持鼠标穿透，避免遮挡 Codex 操作。

## 界面

- 半透明白色收腰胶囊，带轻微阴影。
- 使用完整双圆轨道：左侧绿色表示 5H，右侧蓝色表示 Weekly。
- 剩余额度数字为 18 号，省略百分号；中间显示 W / 5H 标签及浅色分割曲线。

## 验证情况

- 在前期实际使用中，用户已确认拖动宠物、隐藏后再显示宠物、移动 Codex 主窗口三项跟随行为正常。
- 本次将已使用的 0.1.1 安装包重新标记并签名为 1.0.0；校验可执行代码和已初始化数据段没有变化。此校验不等同于重新完成整套桌面行为验收。
- 留档包含旧版真实截图，拍摄于 2026-10-16 17:34:58。

## 已知限制

- 本地临时签名变化后，macOS 可能要求重新添加辅助功能授权。
- 真实跨屏拖动、全屏与桌面切换、睡眠唤醒、断网与退出登录等场景尚未完整实测。
- 本版由既有二进制封存，没有可确认完全匹配的完整源码快照；不会以新版源码冒充。
