# Pet’s Pet 1.4.0

日期：2026-10-17。内部构建号：16。保留独立安装包、匹配源码、更新说明、预览与校验文件，并发布到 GitHub Releases。1.3.0 及更早版本留档保持不变。

## 新增与调整

- 菜单栏新增「组件内容」：自动（默认）、5H＋W 剩余额度、重置倒计时＋W 剩余额度。切换立即生效，重开后保留选择；该设置与深浅外观分别保存。
- 自动模式按官方实际返回的周期选择：有 5H 时显示 5H＋W，只有周周期时显示倒计时＋W。规则不绑定会员类型，兼容未来 Pro 恢复 5H；手动选择不会被套餐或周期变化覆盖。
- 5H＋W 模式保持左绿右蓝；倒计时＋W 模式为左蓝右绿。蓝色 D 显示距周额度重置的天数，保留一位小数；越临近重置，进度越满。重置前不足 0.1 天仍显示 `0.1`，不显示比较符号。绿色 W 继续显示真实周剩余额度。
- 通过官方账号／额度信息识别 Pro 或 Plus。Pro 组件中央增加低透明度 `PRO` 底纹，垫在太极曲线下面：浅色主体用浅色底纹，深色主体用深色底纹。底纹只表示会员身份，Plus 也可使用倒计时模式。
- 固定选择 5H＋W 而账号未提供 5H 时，左圆显示 `--`，菜单说明原因。额度／时间缺失、读取失败、过期或已到重置时间时保留未知状态，等待官方刷新，不自行补满额度。
- 组件主体尺寸仍为 128 × 64 点。简版预览仅保留模式选择、深浅对照与兼容场景；桌面尺寸对照补偿本机网页缩放。预览固定样本不进入正式额度读取。
