# macOS 启动动画

当前 macOS 版本为 **1.7.1（构建 27）**。默认和自定义动画均按 Pet’s Pet「外观」选择明暗；不按钟点另行判断。选择「跟随系统」时使用播放开始时的系统外观，一次播放中固定该套素材和背景，后续播放重新判断。

## 明暗动画与自定义

- 「启动设置 → 浅色动画／深色动画」各自提供选择、预览和恢复默认。导入后预览刚选择的那套；「预览当前外观动画」按当前有效外观播放。
- 默认浅色使用已修正圆形光圈的透明动画，配合浅色系统毛玻璃；默认深色使用用户提供的 Divine 动画，自带深紫金色背景。透明自定义素材仍可透出该套外观的系统毛玻璃，不透明部分由素材自身覆盖。
- 两套可独立使用 HTML、MOV、MP4 或 PNG；一套未设置时使用该套默认动画。导入失败或取消保留原选择。
- 旧版只有一份自定义素材时，升级后先供两套共用，保留原素材与名称；分别更换或恢复默认时，只有不再被任何一套引用的管理副本才会删除。重开软件后选择保留，不改用户原文件。
- 修改范围：素材管理与旧设置迁移 `StartupMediaStore.swift`、菜单与启动入口 `AppDelegate.swift`、原生窗口外观 `StartupAnimation.swift`；增加 `DefaultStartupDark.html`，同步资源构建声明、检查、预览页和文档。

本版安装包与匹配源码已同步至 [GitHub Release](https://github.com/Marwin-M/pets-pet/releases/tag/v1.7.1)。应用退出与重新打开由用户自行操作；Windows 不包含本功能。1.7.0 的既有行为和验证记录保留在下文及对应版本日志。

## 使用行为

- 默认开启「打开 Pet’s Pet 时启动 Codex」和「显示启动动画」，可在菜单栏的「启动设置」分别关闭。
- Codex 未运行时，先显示动画；HTML 首帧可用后再请求启动 Codex。客户端启动和动画同步进行，不强制等完整动画结束。
- Codex 已运行时，直接沿用原组件，不播放开场、不另开实例，也不自动重启 Codex。
- 就绪要求可见的普通主窗口和可操作的主界面。已连接侧栏时确认文档加载完成、导航与可用输入区已渲染、主区域没有加载标记；没有侧栏连接时尝试从已有辅助功能权限确认网页区域及可用多行输入控件。只检测控件和状态，不读取输入内容。窗口壳出现、单纯连接成功和动画播完都不能单独触发退出。
- 10 秒内客户端就绪，则提前渐隐并恢复组件；10 秒后仍未就绪，则保持最后一帧与毛玻璃背景，直到客户端就绪后约 0.8 秒一起淡出。10 秒是默认动画时长，不是启动失败时限。系统开启「减少动态效果」时仍使用即时结束。
- 默认最短显示约 0.8 秒，总等待上限仍为 30 秒。启动失败、提前退出、缺少 Codex 或长时间无法确认就绪会给出提示，不强制结束 Codex。缺少辅助功能权限且未授权本机侧栏连接、登录／设置等无输入区界面、未来 Codex 内部结构变化，可能使就绪无法确认；此时不把窗口壳当作已加载完成。
- 开场结束后恢复组件的跟随／侧栏位置、显示与隐藏、额度内容、外观，以及侧栏各项开关。
- 「启动设置 → 启动 ChatGPT」指向已确认的 Codex 客户端（`com.openai.codex`），手动启动不受自动启动开关影响，固定启用仅限本机的连接参数 `--remote-debugging-address=127.0.0.1 --remote-debugging-port=39222`，随后恢复已开启的侧栏功能。客户端已运行、正在启动、主动重连或应用暂停时禁用；动作执行时再次校验，避免重复启动。此次手动操作不改变未来自动启动的授权选择。
- 「ChatGPT 退出时退出 Pet’s Pet」默认开启：目标客户端真正退出时，Pet’s Pet 随之正常退出并清理连接、监控与窗口。关闭后只隐藏组件，Pet’s Pet 留在菜单栏，可以手动再次启动客户端。选择通过 `quitWithCodex` 保存到本机，下次启动沿用；关闭时取消尚未执行的跟随退出，重新开启不会因客户端当前未运行而立即退出，只处理后续退出事件。
- 只关闭窗口、最小化、隐藏或连接断开不触发跟随退出。若仍有目标客户端实例则继续运行；与目标不同的独立 ChatGPT 应用不在本次范围。既有「启用侧栏连接」主动重启的旧进程退出会被排除，但开关开启时新进程此后真正退出仍一起退出。Pet’s Pet 启动时没有客户端且关闭了自动启动，不会立即自退，也不会自动重启已退出的客户端。手动退出 Pet’s Pet 不会关闭客户端，也不受此开关影响。
- 退出请求交回原生公共事件循环执行，再进行异步清理，避免 AppKit 延迟退出的嵌套循环与 Swift 主执行器互相等待。正常清理完成即确认退出；清理最多等待 2 秒，逾时确认退出本应用。重复退出请求不再次进入退出流程。此上限只作用于 Pet’s Pet，不强制结束或操作客户端。
- 睡眠、锁屏或退出 Pet’s Pet 会取消开场等待；唤醒后恢复原有监控，不自动再次启动 Codex。

## 尺寸和素材

- 默认以用户提供的 `ChatGPT-splash-transparent_k.html` 为基础，直接修改项目内置的 `DefaultStartup.html`，不另生成 HTML 副本。包含 3 秒入场和后续动效，总时长 10 秒；通过原文件的 `splash:done` 事件停住末帧。画面文字按原作保留，实际启动目标仍为 Codex。
- 支持 `.html`／`.htm`、`.mov`、`.mp4`、`.png`，扩展名不区分大小写。视频须有本机可播放的视频轨道和有效时长；静音播放一次，结束后保留最后一帧。PNG 使用静态画面。Codex 提前就绪时可以提前结束所有格式的动画。
- 启动前优先使用上次记录的 Codex 主窗口位置和尺寸；主窗口出现后再次校准。首次没有记录时居中显示，取当前屏幕可用尺寸的 80%，最大 1200 × 850 点。屏幕断开或分辨率变化后自动收回可见范围。此记录只包含矩形，不包含窗口标题或会话内容。
- PNG 和视频均**等比放大铺满窗口、居中裁切**，不拉伸变形。素材主体应放在中央；宽高比与 Codex 窗口不同时，边缘会被裁掉。
- HTML 默认保留作者的响应式布局，不强制按 16:10 裁切。默认素材的人物与文字保持等比，光圈和扩散涟漪保持圆形，不按宽高比分别缩放；粒子、光线和等比绘制的大范围光晕继续覆盖宽屏两侧，随窗口改变。固定画布素材可用 `<meta name="petspet-design-size" content="1920x1200">` 显式声明逻辑尺寸，再由宿主等比铺满和居中裁切。
- HTML 是 UTF-8 单文件，图片、脚本和字体需内嵌；播放结束时发送 `window.dispatchEvent(new CustomEvent('splash:done'))`，或用 `<meta name="petspet-duration" content="10">` 声明秒数。结束信号暂停 RAF、网页动画和媒体，保留画面，不代表 Codex 就绪；静态 HTML 不必声明时长。
- 网页在临时的 WebKit 存储中运行，内容策略禁止联网、读取其他本地文件、嵌套页面、表单提交和打开外部页面，不提供应用数据或原生操作接口。HTML 运行出错或首帧等待超过 5 秒时回退到原生 loading，并继续原启动流程。
- HTML 的透明区域由 Pet’s Pet 在画面后面放置原生 `NSVisualEffectView`，使用 `.behindWindow` 模糊动画窗口背后的内容、`.active` 保持非激活面板的毛玻璃效果。人物、文字与光圈绘制在模糊层上方，预览、首帧等待和末帧等待使用同一层；动画与毛玻璃在同一窗口内统一渐隐。PNG／视频的不透明区域仍由素材自身遮盖背景。使用本次播放选定的明暗外观并遵循「降低透明度」设置，不使用截屏、不申请录屏权限，也不修改客户端实现。macOS WebKit 透明绘制仍保留原有受能力检测保护的兼容设置，其他系统版本待实测。
- 导入上限为 200 MB，PNG 宽高各不超过 4096 像素。素材先验证再替换，失败保留原素材；损坏或丢失时显示默认 loading，不阻断启动。
- 素材复制到 `~/Library/Application Support/PetsPet/StartupMedia/`，原文件移动后不影响使用；替换或恢复默认时删除本功能管理的旧副本，不改原文件。
- 应用内预览只播放一遍：HTML 收到 `splash:done` 或声明时长结束时关闭，MOV／MP4 在实际片尾关闭，默认 HTML 为 10 秒。PNG、未声明时长／结束信号的 HTML，以及加载失败后的提示保留到手动结束，不猜测播放时长。预览右上角与「启动设置」菜单均提供「结束预览」，加载中也可结束；预览不启动 Codex。实际启动仍在末帧等待客户端就绪，且保持鼠标穿透。未制作独立网页预览。

## 侧栏连接

首次由 Pet’s Pet 冷启动 Codex 且有已开启的侧栏功能时，询问是否允许下次自动恢复本机侧栏连接。选择保存到本机，可在「启动设置 → 启动时恢复侧栏连接…」更改；原有「启用侧栏连接…」的明确确认也会保存这项授权。

自动启动只有已有授权且存在开启的侧栏功能时，才传递 `127.0.0.1:39222` 的本机调试参数；用户主动点击「启动 ChatGPT」时本次直接带参启动，不修改 Codex 安装文件或默认启动配置。启动期间最多等待 30 秒恢复侧栏；后续连接中断仍停止重试。Codex 已经运行但没有连接入口时，保留原设置并提示手动连接，不自动重启它。
